## 先搞懂 Claude API 的计费逻辑：预付额度制

Claude API 不收月费，走的是预付额度模式。先充钱进账户，产生用量后从余额里扣，扣完为止。额度用尽之后，API 和 Playground 都会停摆，直到你再次充值。

几个容易被忽略的计费细节，提前说清楚：

- 只对成功的 API 调用和已完成的任务收费，失败的请求不计费。
- 有一个例外：如果客户端在一次即将成功的请求中途断开连接或超时，这笔请求照样计费。写代码处理超时逻辑时留意一下。
- 官方帮助文档写明，预付额度涵盖 API 访问、Playground 使用和编码代理的消耗。

另外，通过 Anthropic 销售团队开通了发票安排的组织可以按月后付，月末统一收到 Stripe 发票再付款。这条只面向企业客户，普通个人账户开不了，不用纠结。

## 官方充值步骤：五步走完

1. 用管理员或计费角色的账号登录 Claude Console。
2. 进入设置里的 Billing（计费）页面。
3. 点击“购买额度”。
4. 输入要充的金额并确认。
5. 额度立即可用，余额和消耗明细都在同一个 Billing 页面查看。

注意第一步里的角色限制：只有管理员或计费角色能操作购买，普通成员进去看不到入口。

### 建议顺手开启自动充值

长期跑 API 的人，手动充值最大的风险是余额归零时服务突然中断。Console 的 Billing 页面里有自动充值功能：设一个最低余额阈值和一个固定充值金额，余额跌破阈值就自动补进对应额度。比如余额低于 10 美元时自动充 50 美元，具体数字自己按用量定。

### 额度过期和退款规则，充值前必须知道

> 额度自购买之日起一年内有效，过期日无法延长；所有额度购买都不可退款。过期的额度会显示在计费页面的发票历史里。

这条规则直接决定了充值策略：**不要囤额度**。按一两个月的用量节奏充，比一次充一年的量稳妥得多，尤其是不确定项目能不能跑下去的时候。

## 付款方式的现实：官方只认美元通道

把官方支持的付款方式列出来，问题就很直观了：Visa、Mastercard、American Express 信用卡，以及 PayPal（需要绑外币卡）。国内的银联卡、支付宝、微信，在官方收银台都走不通。

Anthropic 是美国公司，全球统一美元结算，没有在国内铺设本地支付通道。这不是针对谁，是绝大多数海外 AI 产品的通病。国内用户想给 API 线充值，只能在下面几条路里选。

顺带一提，如果以后换了新卡，Billing 页面里点当前付款方式旁的铅笔图标就能更新卡信息，不用重新绑。

### 领取步骤和四个坑

领取入口在 Claude 网页版：设置 → Billing → API credits，把你的订阅链接到一个 Console 组织，确认后额度到账。个人身份也能建 Console 组织，不需要公司资质。

坑有四个，都不复杂但真会让人吃亏：

1. 订阅需要激活满 7 天才能领，新开的账号等一周。
2. 组织只能链接一次，之后**不能自己更换**。链接前想清楚用哪个。
3. 不领取就等于没有。赠额不结转，当月没用完的下月清零，拖着不领的那个月就是纯损失。
4. 到账日期和订阅续费日不一定同一天。有用户反馈订阅月底续费，额度却隔了两天才到账，想掐着日期用完的人以页面上显示的下期到账日为准。

算笔账：Max 20x 每月 $200 的赠额，基本等于订阅费里已经把 API 这条线覆盖了。如果你本来就在用 Max 或 Team，这是白拿的钱，先去领。只用 Pro 的拿不到这个福利，这个差距选套餐时可以纳入考虑。

### 虚拟信用卡：能走通，坑要提前知道

大致流程：在虚拟卡平台注册账号、充值、开一张虚拟 Visa 或 Mastercard，然后回到 Console 的 Billing 页面绑卡，Stripe 支付页里填卡号、有效期、CVC 和账单地址，账单地址建议用美国地址。

三个最常见的失败原因：网络环境没让 Stripe 识别到支持地区、虚拟卡本身不支持国际扣款、Stripe 风控直接拒了。遇到绑定失败，换账单地址或换一张卡再试是常规操作。

绑卡成功后别急着大量充值，先做一件事：在 Billing 设置里配置用量上限或月度预算。API 按 token 计费，没有固定月费，跑飞了的脚本一晚上能烧掉不少额度，上限这道保险很便宜。

## 常见问题

**Claude API 充值支持支付宝或微信吗？**

官方不支持，银联也不行。想用人民币付款，要么走第三方渠道（是否收人民币以下单页为准），要么用虚拟信用卡曲线。目前没有官方的人民币通道。

**API 充值和 Claude Pro 订阅是一回事吗？**

不是。API 账户面向开发者，按 token 用量计费，预充值消费；Pro 是面向普通用户的网页版会员，$20/月，自带的是聊天和编码代理的订阅额度。两边账目独立。唯一的交集是 Max 和 Team 订阅现在每月赠送一笔 API 额度。

**Max 的每月赠额没领会怎样？**

不领取就等于没有，赠额不结转，拖过当月直接作废。另外链接 Console 组织这一步不做，额度会一直挂着到不了账，链接过的组织还不能自己更换。领之前把组织选好。

**第三方渠道充值安全吗？会不会封号？**

风险主要看充值方式。充值进入你自己账户、全程不交密码的模式，账户控制权始终在你手里，风险比代登录低得多。真正危险的是把账号密码交给别人操作，那种方式无论价格多好都不要用。另外渠道再干净，也代替不了你遵守 Anthropic 的使用政策，账号本身的合规是前提。

**失败的请求收费吗？**

不收，只为成功的调用和已完成的任务付费。但注意边界情况：请求已经接近成功时客户端断开或超时，这笔仍会计费。
